# DevOps-лаборатория: проект «Notes»

Учебный проект для практики DevOps. Код приложения писать не нужно: вы — «DevOps-инженер компании», которому разработчики передали сервис и сказали: «Задеплойте, автоматизируйте, следите, чтобы работал».

## Что за сервис

Маленький веб-сервис заметок (Python/Flask):

| Компонент | Роль |
|---|---|
| `app/app.py` | API + главная страница, запускается через gunicorn |
| PostgreSQL | хранит заметки |
| Redis | счётчик посещений |

Эндпоинты:

| URL | Что делает |
|---|---|
| `GET /` | страница со счётчиком посещений (Redis) |
| `GET/POST /api/notes` | список заметок / добавить `{"text":"..."}` (Postgres) |
| `GET /health` | 200 если БД и Redis живы, иначе 503 |
| `GET /metrics` | метрики для Prometheus |
| `GET /chaos/slow?sec=5` | медленный ответ |
| `GET /chaos/error` | ошибка 500 |
| `GET /chaos/leak?mb=50` | «утечка памяти» (`/chaos/reset` сбрасывает) |
| `GET /chaos/cpu?sec=10` | загрузка CPU |

`/chaos/*` работают только при `CHAOS_ENABLED=true`. Это ваши «ломалки» для этапов с диагностикой и мониторингом.

## Конфигурация (переменные окружения)

| Переменная | По умолчанию |
|---|---|
| `DB_HOST`, `DB_PORT` | `localhost`, `5432` |
| `DB_NAME`, `DB_USER`, `DB_PASSWORD` | `notes`, `notes`, `notes` (в проде пароль другой!) |
| `REDIS_HOST`, `REDIS_PORT` | `localhost`, `6379` |
| `LOG_LEVEL` | `INFO` |
| `CHAOS_ENABLED` | `false` |

Команда запуска приложения (важно: именно **1 worker**, чтобы метрики и «утечка» считались корректно):

```
gunicorn -w 1 --threads 4 -b 127.0.0.1:8000 app:app
```

Проверка локально: `curl localhost:8000/health`.

## Как работать

Этапы идут по порядку, у каждого файл в `tasks/`:

1. `01-linux-deploy.md`: ручной деплой на ваш сервер
2. `02-incidents.md`: расследование поломок (метрики, логи, причины)
3. `03-docker.md`: контейнеризация и docker-compose
4. `04-cicd.md`: автоматический деплой из Git
5. `05-iac.md`: сервер как код (Ansible, по желанию Terraform)
6. `06-monitoring.md`: Prometheus, Grafana, алерты
7. `07-kubernetes.md`: перенос в Kubernetes (k3s)

Правила:
- **Готовых решений в архиве нет, это сделано специально.** В каждом задании есть цель, шаги, критерий «готово» и подсказки. Застряли — присылайте мне вывод команд и логи, будем разбирать вместе.
- Ведите свой Git-репозиторий и файл `NOTES.md`: что сделали, что сломалось, как починили. Это ваш личный runbook и будущее портфолио.
- Работайте на **тестовом** сервере, где не страшно ломать. Перед опасными упражнениями делайте снапшот у хостера.
- Каждый этап заканчивайте пунктом «Готово, если…». Пока он не выполнен, дальше не идём.

```
pip install -r requirements.txt
```
